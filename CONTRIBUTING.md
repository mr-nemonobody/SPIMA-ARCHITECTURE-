# Contributing to SPIMA

Thank you for your interest in contributing to the Sovereign Predictive Isolation Manifold (SPIMA) project. To ensure smooth collaboration while protecting proprietary assets, please review the guidelines below.

## Scope of Contributions
* **Encouraged:** Macro-level architectural patterns, cross-industry deployment frameworks (e.g., data centers, aerospace, containment), documentation refinements, and discussion-based design proposals.
* **Out of Scope / Prohibited:** Low-level proprietary implementation details, microsecond timing arrays, raw HDL source files, and proprietary simulation data. Submissions containing protected trade secrets will not be merged.

## Pull Request Process
1. Open a GitHub Discussion under **Ideas** or **Q&A** before starting major changes to align with maintainers.
2. Fork the repository and create your feature branch from `main`.
3. Ensure your submissions strictly respect trade-secret boundaries and patent-pending frameworks.
4. Submit a pull request with a clear description of the problem solved and the target use case.
