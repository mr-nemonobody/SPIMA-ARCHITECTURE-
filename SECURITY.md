# Security Policy

## Reporting a Vulnerability
The Sovereign Predictive Isolation Manifold (SPIMA) architecture relies on strict physical and combinatorial fault-containment safety bounds. If you discover a security vulnerability or safety edge-case within the public documentation or reference logic, please report it privately rather than opening a public issue.

* **Email:** Send your findings directly to the project maintainer via private communication channels or the designated security email address.
* **Response Timeline:** You can expect an acknowledgment of your report within 48 hours, followed by a detailed assessment and remediation plan.

Please do not disclose security vulnerabilities publicly until maintainers have addressed and resolved the issue.
